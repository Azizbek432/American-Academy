- **Zamonaviy UI/UX:** American Academy brend ranglariga mos, minimalistik va professional dizayn.

# 🇬🇧 American Academy — Landing Page

A modern, responsive landing page web application with a live backend integration, developed for the "American Academy" learning center located in Xonqa.

## 🌐 Live Demo

The project is fully deployed and production-ready. You can check the live version here:
👉 **[american-academy-xonqa.vercel.app](https://american-academy-xonqa.vercel.app/)**

## ✨ Features:

- **Modern UI/UX:** Clean and professional interface tailored to the brand's corporate identity.
- **Fully Responsive:** Perfectly optimized for desktops, tablets, and smartphones.
- **Live Backend Integration:** Integrated with Formspree API to forward lead submissions directly to the administrator's inbox.
- **Smart Validation:** Robust client-side JavaScript validation for phone numbers and required fields.

## 🛠 Tech Stack:

- **HTML5** — Semantic markup.
- **CSS3** — Modern styling utilizing Flexbox, Grid, and CSS variables.
- **JavaScript (ES6+)** — Fetch API, asynchronous request handling, and validation.
- **FontAwesome** — Vector icons integration.
